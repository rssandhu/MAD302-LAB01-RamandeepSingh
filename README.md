## Project Overview
**ProfileListApp** is a single-screen Android application that allows users to input a name and age, create `Profile` objects, add them to an in-memory list, and display all profiles in the required format: `Name – Age`.

## Features
- [x] Single screen (`MainActivity`) with vertical LinearLayout
- [x] Two `EditText` fields (Name, Age)
- [x] `Add Profile` button with click logic
- [x] `TextView` displaying profiles using for loop: `Nevin – 22`
- [x] `Profile.kt` data class with `name: String`, `age: Int`
- [x] `mutableListOf<Profile>()` to store profiles
- [x] Complete Activity lifecycle logging (`onCreate`, `onStart`, `onResume`, `onPause`, `onStop`, `onDestroy`)
- [x] Full documentation (file headers, class/method comments, inline comments)
